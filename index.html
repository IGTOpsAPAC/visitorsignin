📧 Email notifications

Send email to host via Power Automate when visitor arrives. Uses APAC SC Operational Excellence sender.

▶ How to set up the Power Automate flow
  1. Teams → Workflows → "Send webhook alerts to a channel"
  2. Remove "Post card in a chat or channel" action
  3. Add Data Operations → Compose, rename to Decode VSS event
  4. Expression: json(base64ToString(triggerBody()?['sections']?[0]?['text']))
  5. Add Office 365 Outlook → Send an email (V2)
  6. To / Subject / Body: use outputs from Decode VSS event → email object
  7. Copy webhook URL from trigger → paste above
